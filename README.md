# Project **CULTURE-LAB**

ゲームを用いて認知症予防を目指すプロジェクトです。

プロジェクトでは、さまざまなゲームを提供します。

- Blocken-Out
- Calculate-Curling
- Maze-Mission

## プロジェクトについて

このプロジェクトでは、高齢者の認知予防を行うためにゲームを開発しています。

ゲームの作成には、主に生成AIツールを使用しています。

## 使用ツール
- [Arena](https://arena.ai/)
- [Codex Cloud](https://chatgpt.com/codex/cloud)
- [Google Antigravity](https://antigravity.google/)
